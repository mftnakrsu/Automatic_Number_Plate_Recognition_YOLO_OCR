## One read, start to finish

The detector finds the plate, the OCR model reads `34ABC1Z34`, and the parser knows that the last
block of a Turkish plate is digits, so the `Z` becomes a `2`. The result is checked against the 81
province codes:

<div class="read">
  <p class="plate" aria-label="Number plate 34 ABC 1234">
    <span class="band">TR</span>
    <span class="text">34 ABC 1234</span>
  </p>

```json
{
  "raw_text": "34ABC1Z34",
  "normalized_text": "34ABC1234",
  "parsed": {
    "country": "tr",
    "province_code": "34",
    "province_name": "İstanbul",
    "letters": "ABC",
    "digits": "1234",
    "canonical": "34 ABC 1234"
  }
}
```

</div>

On a video stream the same plate is read on many frames. A per-character vote over the best reads
settles it, and only then is it stored, as an HMAC-SHA256 hash.

<CardGrid>
  <Card title="Detection" icon="magnifier">
    A YOLOv9-t ONNX model from [fast-alpr](https://github.com/ankandrew/fast-alpr), trained on
    plates from more than 65 countries. Runs on a plain CPU.
  </Card>
  <Card title="OCR with confidences" icon="document">
    [fast-plate-ocr](https://github.com/ankandrew/fast-plate-ocr) reads the cropped plate and gives
    a confidence for every character. It can also run on CUDA or OpenVINO.
  </Card>
  <Card title="Plate rules by country" icon="approve-check">
    Türkiye's 81 province codes by default, and Germany, France, Italy, Spain, Belgium and
    Portugal when you turn them on. Characters that look alike, such as 0 and O, 1 and I, or 8 and
    B, are fixed by position. See [Plate formats](/guide/plate-formats/).
  </Card>
  <Card title="Tracking and voting" icon="list-format">
    An IoU tracker follows each plate across frames, and a majority vote per character position
    decides the final reading.
  </Card>
  <Card title="Privacy by default" icon="seti:lock">
    The database holds a keyed hash, never the plate text, and old rows are deleted after 30 days.
    See [Privacy](/operations/privacy/).
  </Card>
  <Card title="Ready to run" icon="rocket">
    `pip install`, Docker or `uv`. REST and WebSocket endpoints, a small web page with webcam
    support, Prometheus metrics and optional OpenTelemetry.
  </Card>
</CardGrid>

## Built in the open

anpr-pipeline is free software under the MIT License. It started in 2022 as a YOLOv5, EasyOCR and
Flask project and was rewritten in 2026. The old code is still in the repository's `legacy/`
folder.
